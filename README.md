[imghash](https://github.com/pwlmaciejewski/imghash) command-line interface

> [!IMPORTANT]
> **This package has moved.** Find its current source and documentation in the [imghash monorepo](https://github.com/pwlmc/imghash/tree/master/packages/imghash-cli).

## Installation

```sh
npm i -g imghash-cli imghash
```

## Usage

```sh
imghash [-b BITS] [-f FORMAT] ./path/to/image.png
```
